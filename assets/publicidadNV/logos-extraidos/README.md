# Logos extraídos

Se generaron **61 archivos SVG independientes** a partir de `LOGOS MARCAS.svg`.
Cada archivo conserva las máscaras y rutas de recorte que necesitaba el elemento original.

- Elementos con imágenes embebidas: 43
- Elementos compuestos solo por paths: 18
- Los nombres son numéricos porque el SVG original no incluía nombres de marca.
- Consulta `manifest.csv` para ver la composición de cada archivo.
